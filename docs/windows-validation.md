# Windows 实机验收

本项目在 macOS 主机交叉编译；这里的交互和硬件验收尚未执行。`tests/DisplayQuickControl.WindowsSmoke` 是只读 UI/热键检查，不会应用显示预设。GitHub Actions 已配置 Windows 构建、测试和发布，但本地创建 workflow 不代表云端已运行。

1. 在 Windows 11 解压 x64 自包含包，双击 exe；应只出现托盘图标，不弹主窗口。
2. 单击、双击、键盘激活托盘图标；面板应可打开。右键检查四个菜单项。退出后图标消失。
3. 再运行同一 exe；原进程面板应打开，第二个进程应退出。
4. 在 100%、125%、150%、175%、200% 分别打开面板；测试主屏、副屏、负坐标布局、混合缩放，以及自动隐藏任务栏。弹出面板应处于托盘所在显示器工作区内，错误提示变长后也应保持可见和可滚动。
5. 点击外部和按 Esc 应隐藏面板；取消设置里的外部关闭后，失焦应保留面板。打开设置后，切换到其他应用，设置窗口应保留。
6. 对照 Windows 高级显示页面检查显示器、GPU、分辨率、刷新率、HDR、色深及编码。切换面板的显示器下拉选项，重启后应记住。断开已选屏后应显示不可用，不冒用另一块屏幕。
7. 用 Windows 自己的 HDR 开关改变状态后重新打开/刷新面板，卡片应反映真实值。注意：面板读取的是选择的屏幕；预设必须同样指向该屏幕。
8. 在 ColorControl 手动确认三个预设，然后在应用设置里配置路径。分别应用 SDR 180、HDR Safe 120、HDR 180（8bit）；对照 Windows 检查结果，不能只看命令是否退出。

预设初始化验收：先退出 ColorControl，点击设置中的“初始化 ColorControl 预设”，确认新增三个预设且当前显示状态不变；再次初始化不重复添加。添加自定义模式后保存，检查对应预设的 Include、分辨率、刷新率、HDR、色深、编码和目标显示器。修改模式再次保存，确认 ID 保持不变且有原文件备份；无关预设保留。ColorControl 正在运行且需要写入时，应提示先退出并保留编辑草稿；损坏或并发修改的预设文件不得被覆盖。
9. 连续快速点击模式和按快捷键，应只执行一次预设；Loading 时所有模式不可用。新系统从 HDR 切 SDR 时先用独立 HDR API 关闭 HDR，连续两次读取到关闭后再执行 SDR 颜色预设。ColorControl 退出后等待约 1.8 秒，再连续核对两次稳定状态，不应自动重放预设。
10. 改成不存在的预设名，应用一次；应显示失败/不匹配，不能重试。HDR Safe 建议按钮只在用户点击后执行。
11. 路径为空/失效、色深与预期不符、显示器暂时断连时，应显示明确错误；不能崩溃或循环切换。ColorControl 超时但进程存活时，后续切换应被拒绝。
12. 配置一个已占用快捷键，应显示注册失败原因；修改/禁用快捷键后应立即生效。
13. 设置 System，改变 Windows 深浅色；再测试强制 Dark / Light。检查 hover、pressed、active、disabled、loading 和键盘焦点。
14. 启用开机启动后注销再登录，应进入托盘；关闭选项后再次登录不应启动。可在任务管理器的启动应用中检查。
15. 修改安装目录后重新保存开机启动选项，以更新 exe 路径。
16. 关闭程序后损坏 settings.json，再启动应使用默认配置；日志应保持有限大小和数量。
17. 保持面板隐藏约 5 分钟，观察任务管理器 CPU 应接近 idle；无常驻显示状态轮询。面板短暂动画和切换期间允许瞬时占用。
18. 主面板点击“自定义模式”，新增一个模式，配置名称、预设、不同分辨率、小数刷新率、HDR、色深、颜色编码和快捷键；保存后卡片应立即出现。上移 / 下移后的顺序应保持，重启后仍在。
19. 修改或删除原有模式，应立即更新卡片和热键；删除后旧快捷键不能再执行。至少保留一个模式，空名称、重复名称、空预设、非法分辨率和刷新率应阻止保存。
20. 编辑模式后取消或关闭窗口，原配置不应改变。从 Settings 打开编辑器并保存后，取消整个 Settings 也应放弃这份草稿；只有 Save settings 才持久保存。
21. 更换手动备用模式，旧备用标记应自动清除。其他 HDR 模式失败时只提示当前指定的备用模式，不自动执行；未指定时不提示固定 HDR-120。
22. 使用旧版 settings.json（自定义预设名、空快捷键等）启动，三个模式应迁移并保留原值。修改模式后再保存，配置应使用 Modes 列表，后续重启不能丢失。
23. 模式编辑窗口打开后失焦应保留；输入期间全局模式热键不应触发显示切换。保存时如快捷键与外部软件冲突，应明确提示“已保存但快捷键不可用”。

24. 在 Windows“颜色管理”中分别将“自动管理应用的颜色”设为开和关；刷新面板核对 ACM 行。分别测试 HDR 180 → SDR 180、HDR 120 → SDR 180、SDR → HDR，确认每次切换保留原 ACM 选择。同一张 SDR 图片的灰阶、白色及饱和度应恢复一致。若仍异常，记录模式、ACM、色深、编码和 NVIDIA Full / Limited 动态范围；不能仅凭 HDR Off 判定颜色正常。此项需实机人工确认。

目前程序验证切换后连续两次匹配且信号参数稳定的状态，无法证明 DP 链路长期稳定，也不会尝试诊断电缆、DSC 或显示器固件。
